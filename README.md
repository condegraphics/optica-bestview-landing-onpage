# Óptica Best View — landing one-page

Frontend estático con HTML semántico y CSS responsive, pensado para la revisión visual de la landing.

- `index.html`: contenido, metadatos SEO, datos estructurados y enlaces.
- `styles.css`: diseño adaptable, accesibilidad y estilos.
- `img/`: logo, fotografías y video aportados para el proyecto.
- Tipografías: Bricolage Grotesque (títulos) y Roboto (texto), servidas por Google Fonts.

La vista de revisión lleva `noindex` para no competir con el sitio oficial. Revisar canonical, indexación, horarios y datos de contacto antes de cualquier reemplazo o publicación en producción.
